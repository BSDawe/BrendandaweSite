# brendandawe.ca

Personal site built with [Astro](https://astro.build) and deployed to GitHub Pages.

- Pages: `src/pages/` (home, CV, contact, research and analysis)
- Blog posts: Markdown files in `src/content/writing/` (set `draft: false` to publish)
- Local preview: `npm install && npm run dev`
- Deploys automatically on push to `main` (see `.github/workflows/deploy.yml`)
- Custom domain: `public/CNAME`
